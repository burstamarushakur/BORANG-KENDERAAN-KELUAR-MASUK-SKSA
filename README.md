# BORANG KELUAR MASUK KENDERAAN PELAWAT SK SUNGAI ABONG

Web app pendaftaran kenderaan pelawat sekolah, menggunakan React + Vite + Tailwind dan Google Apps Script sebagai backend secara terus (`text/plain` webhook).

## Cara Menjalankan
1. Copy `.env.example` jadikan `.env`
2. Run `npm install`
3. Run `npm run dev`

## Deploy
Run `npm run build` untuk memproses kod `src` menjadi folder `dist` untuk hosting (Vercel, Netlify, Github Pages, dll).
Tidak menggunakan server Node.js khusus.
